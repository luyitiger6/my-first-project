# wanderchain-profile Specification

## Purpose
为 wanderchain 提供可被内容流识别的作者身份：账户可以维护昵称、头像、简介与兴趣标签四项资料，内容流按对外标识批量取得只含昵称与头像的公开名片，从而使帖子作者从一串标识变成可辨认的人。

## Requirements

### Requirement: 资料字段口径

个人资料 SHALL 由昵称、头像地址、简介、兴趣标签四项构成。昵称 MUST 为去除首尾空白后 1 至 64 个字符；简介 MUST 不超过 200 个字符，允许为空。任一条件不满足时 MUST 返回 `400` 与 `VALIDATION_FAILED`，且 MUST NOT 修改任何字段。

#### Scenario: 昵称为空白被拒

- **WHEN** 已登录用户提交去除首尾空白后为空的昵称
- **THEN** 返回 `400` 与 `VALIDATION_FAILED`，账户昵称保持原值

#### Scenario: 昵称超长被拒

- **WHEN** 已登录用户提交超过 64 个字符的昵称
- **THEN** 返回 `400` 与 `VALIDATION_FAILED`，账户昵称保持原值

#### Scenario: 简介超长被拒

- **WHEN** 已登录用户提交超过 200 个字符的简介
- **THEN** 返回 `400` 与 `VALIDATION_FAILED`，简介保持原值

#### Scenario: 合法资料保存成功

- **WHEN** 已登录用户提交合法的昵称、头像地址、简介与标签集合
- **THEN** 返回 `200` 与保存后的完整资料，四项取值与提交值一致

### Requirement: 兴趣标签取值边界

兴趣标签 SHALL 最多 5 个，每个 1 至 16 个字符，按值去重，且 MUST 全部来自服务端提供的标签清单。清单之外的值、超过数量上限、长度越界 MUST 被拒绝并返回 `400` 与 `VALIDATION_FAILED`，且 MUST NOT 修改任何字段。

#### Scenario: 第六个标签被拒

- **WHEN** 已登录用户提交 6 个标签
- **THEN** 返回 `400` 与 `VALIDATION_FAILED`，已保存的标签不变

#### Scenario: 清单外标签被拒

- **WHEN** 已登录用户提交一个不在服务端清单内的标签
- **THEN** 返回 `400` 与 `VALIDATION_FAILED`，已保存的标签不变

#### Scenario: 重复取值去重后保存

- **WHEN** 已登录用户提交含重复取值的标签集合
- **THEN** 保存的是去重后的集合，读取资料时每个标签只出现一次

### Requirement: 头像地址不代抓取

头像地址 MUST 为空或合法的 `http(s)` 绝对地址。服务端 MUST NOT 为校验头像地址发起任何外部网络请求，MUST NOT 代下载或转存头像文件。

#### Scenario: 非法头像地址被拒

- **WHEN** 已登录用户提交非 `http(s)` 的绝对地址或含协议的相对路径作为头像
- **THEN** 返回 `400` 与 `VALIDATION_FAILED`，头像保持原值

#### Scenario: 外链头像不触发服务端外网请求

- **WHEN** 已登录用户提交一个合法但不属于本站托管前缀的头像地址
- **THEN** 资料保存成功，且服务端未对该地址发起任何网络请求

### Requirement: 资料读取的可见性边界

本人完整资料 MUST 要求有效令牌。他人名片 MUST 无需登录即可读取，且只包含对外标识、昵称与头像地址三个字段。批量读取 MUST 一次接受 1 至 50 个对外标识，超出上限 MUST 返回 `400`；不存在或已注销的标识 MUST 从结果中省略，MUST NOT 使整批失败。

#### Scenario: 未登录读本人资料被拒

- **WHEN** 未携带有效令牌请求本人完整资料
- **THEN** 返回 `401` 与 `UNAUTHENTICATED`

#### Scenario: 游客批量读名片只含三个字段

- **WHEN** 未登录请求一批存在的账户对外标识
- **THEN** 每个名片恰含对外标识、昵称与头像地址，不含简介、兴趣标签、邮箱与状态

#### Scenario: 批量超过上限被拒

- **WHEN** 一次请求 51 个对外标识
- **THEN** 返回 `400` 与 `VALIDATION_FAILED`，不返回任何名片

#### Scenario: 未知标识被省略

- **WHEN** 一批标识中含不存在或已注销的对外标识
- **THEN** 该标识不出现在结果中，其余存在的标识正常返回

### Requirement: 更新仅限本人且为部分更新

资料更新 MUST 只作用于令牌所代表的账户，MUST NOT 存在按对外标识修改他人资料的入口。更新为部分更新：未提交的字段 MUST 保持原值，提交空字符串按清空处理。未登录 MUST 返回 `401` 与 `UNAUTHENTICATED`；跨站来源 MUST 返回 `403` 与 `CROSS_SITE_REJECTED`，且来源校验先于认证。

#### Scenario: 登录用户更新成功

- **WHEN** 已登录用户提交对自己资料的合法修改
- **THEN** 返回 `200` 与更新后的资料，修改已生效

#### Scenario: 未登录更新被拒且不写入

- **WHEN** 不带有效令牌提交资料更新
- **THEN** 返回 `401` 与 `UNAUTHENTICATED`，且任何资料字段都未被修改

#### Scenario: 跨站更新先于认证被拒

- **WHEN** 一个跨站来源请求同时缺少有效令牌
- **THEN** 返回 `403` 与 `CROSS_SITE_REJECTED`，不是 `401`

#### Scenario: 部分更新不覆盖未提交字段

- **WHEN** 已登录用户只提交简介，未提交昵称、头像与标签
- **THEN** 简介被更新，其余三项保持原值

### Requirement: 昵称与既有显示名同源

昵称 MUST 与账户既有显示名共用同一存储。编辑昵称后，用户信息接口 MUST 立即返回新昵称，且该响应的字段集合 MUST 保持 `publicId`、`email`、`displayName`、`status`、`createdAt` 五项不变。

#### Scenario: 改名后用户信息返回新昵称

- **WHEN** 已登录用户把昵称改为新值后请求用户信息接口
- **THEN** 响应中的 `displayName` 为新昵称

#### Scenario: 用户信息字段集合不变

- **WHEN** 请求用户信息接口
- **THEN** 响应字段集合仍是既有五项，未因资料新增字段而扩张

### Requirement: 兴趣标签清单可匿名读取

服务端 SHALL 提供无需登录即可读取的兴趣标签清单，清单 MUST 非空，且 MUST 是资料更新校验与界面展示的唯一真源。

#### Scenario: 清单可匿名读取

- **WHEN** 未登录请求兴趣标签清单
- **THEN** 返回非空清单，不返回鉴权错误

#### Scenario: 清单内的值可保存

- **WHEN** 已登录用户提交一个来自当前清单的标签
- **THEN** 资料保存成功，读取时该标签可见

### Requirement: 个人中心的入口与访问边界

已登录用户 MUST 能从站点任一页面经不超过 2 次点击到达个人中心，个人中心 MUST 展示昵称、头像、简介与兴趣标签四项的当前值并允许编辑。未登录访问个人中心 MUST NOT 发起资料读取请求，MUST 展示登录引导入口。保存成功后 MUST 跳转到广场并展示服务端返回的新值，且站点顶栏昵称 MUST 同步为新值；保存失败 MUST 保留用户已输入的内容并展示可读错误。

#### Scenario: 登录用户一键到达个人中心

- **WHEN** 已登录用户在任一站点页面点击账户菜单中的个人中心入口
- **THEN** 进入个人中心并展示当前四项资料

#### Scenario: 未登录访问不发起资料请求

- **WHEN** 未登录用户直接访问个人中心路径
- **THEN** 页面展示登录引导入口，且未发出任何资料读取请求

#### Scenario: 保存成功后跳转广场并同步顶栏

- **WHEN** 已登录用户在个人中心把昵称改为新值并保存成功
- **THEN** 页面跳转到广场，站点顶栏无需刷新即显示新值，广场中该用户的帖子卡片展示新昵称

#### Scenario: 保存失败保留输入

- **WHEN** 已登录用户提交的资料被服务端以 `400` 拒绝
- **THEN** 输入内容保持不变，并展示与拒绝原因对应的可读提示

### Requirement: 头像上传复用既有媒体通道

个人中心的头像字段 MUST 同时支持上传与手填地址。选择图片后 MUST 立即调用既有媒体上传端点，并把返回地址回填到头像字段；上传进行中 MUST 阻止保存；上传失败 MUST 保留字段原有内容并给出可读提示，MUST NOT 覆盖用户已填写的地址。

#### Scenario: 上传成功后回填并预览

- **WHEN** 已登录用户在个人中心选择一张本地图片并等待上传完成
- **THEN** 头像字段被回填为上传返回的地址，页面上出现该头像预览

#### Scenario: 上传失败保留原值

- **WHEN** 头像字段已填有地址，用户随后选择图片但上传被拒绝
- **THEN** 字段仍是原地址，并显示可读的错误提示
