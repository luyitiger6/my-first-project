# Spec Delta

## MODIFIED Requirements

### Requirement: 结果展示与空态（英文字段）

搜索结果 SHALL 为每个有命中的分组展示组名、命中条数与条目；条目 MUST 展示标题的英文字段与所属城市的英文名，所属城市为 `all` 时 MUST 展示全城范围的英文表述，分组名与回链文案 MUST 为英文；景点条目 MUST 渲染为指向 `/attractions/<publicId>` 的链接，编辑推荐与帖子条目 MUST NOT 渲染为链接元素。每个分组 SHALL 提供返回首页对应区块的锚点链接；全部无命中时 MUST 展示英文空态文案与回首页入口。

#### Scenario: 只呈现有命中的分组

- **WHEN** 一次检索只命中一类内容
- **THEN** 页面只出现该类内容的分组，其余分组不出现也不留空标题

#### Scenario: 结果条目不构成死链

- **WHEN** 结果条目渲染完成
- **THEN** 景点条目是链接元素且指向 `/attractions/<该景点的 publicId>`；编辑推荐与帖子条目不是链接元素；页面不出现指向不存在地址的任何链接

#### Scenario: 条目文案取自英文字段

- **WHEN** 检索命中一条内容
- **THEN** 条目展示的标题与城市名均取自英文字段，所属城市为 `all` 时展示全城范围的英文表述，条目文本不含中文字符

#### Scenario: 零命中空态

- **WHEN** 关键词在全部内容中都没有命中
- **THEN** 页面展示无结果文案，并提供返回首页的入口

#### Scenario: 分组回链可达

- **WHEN** 用户点击某分组末尾的回链
- **THEN** 浏览器导航到首页中该内容类别对应的区块锚点

### Requirement: 服务端渲染与零请求

搜索页 SHALL 渲染站点头部与页脚，MUST 在服务端完成检索与数据读取，MUST NOT 在浏览器端发起任何 fetch 或 XHR 请求，MUST NOT 依赖客户端状态。景点数据源不可达时该分组 MUST 缺席或展示英文不可用提示，其余分组 MUST 照常渲染。

#### Scenario: 无客户端脚本也能出结果

- **WHEN** 客户端脚本被禁用后访问带关键词的搜索页
- **THEN** 结果分组与条目仍然可见

#### Scenario: 零网络请求

- **WHEN** 搜索页在浏览器中完成渲染
- **THEN** 浏览器端不产生任何 fetch 或 XHR 请求

#### Scenario: 景点数据源失败不阻断其它分组

- **WHEN** 服务端读取景点数据失败，而编辑推荐与帖子仍可检索
- **THEN** 编辑推荐与帖子分组照常展示，页面不返回服务端错误，景点分组缺席或展示英文不可用提示

#### Scenario: 页面结构可读

- **WHEN** 搜索页渲染完成
- **THEN** 页面只有一个一级标题，且包含站点头部与页脚
