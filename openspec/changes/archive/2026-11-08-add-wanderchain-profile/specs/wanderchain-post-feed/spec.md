# Spec Delta

## MODIFIED Requirements

### Requirement: 真实帖子卡片与详情入口

广场卡片 SHALL 展示真实接口的标题、可用封面、标签、作者昵称与头像、创建时间以及点赞、评论、收藏数。作者昵称与头像 MUST 取自按对外标识批量读取的公开名片，MUST NOT 由前端拼装或使用其他来源。互动统计 MUST 使用单色 outline 图标与英文数字，零值不隐藏；卡片 SHALL 提供基于 `publicId` 的详情链接。页面 MUST NOT 编造摘要、作者昵称、城市或浏览数，MUST NOT 将 Mock 数字 ID 用于真实请求，MUST NOT 在任何状态下把 26 位作者对外标识渲染给用户。

#### Scenario: 真实卡片字段完整

- **WHEN** 广场列表请求成功且对应名片已返回
- **THEN** 每张卡片呈现后端标题、标签、作者昵称与头像、创建时间和三项统计，封面存在时显示封面，不读取 Mock 英文字段

#### Scenario: 图标化统计行

- **WHEN** 用户查看真实帖子卡片
- **THEN** 卡片底部以横向图标加数字展示赞成票、评论、收藏，语义可辨识

#### Scenario: 零互动仍展示

- **WHEN** 某条帖子的三项统计均为 0
- **THEN** 卡片仍展示三个图标及数字 0

#### Scenario: 点击进入真实详情

- **WHEN** 用户激活某张卡片的标题或详情链接
- **THEN** 导航到 `/posts/{publicId}`，标识来自该真实列表项，链接可由键盘操作

#### Scenario: 封面不可用

- **WHEN** 后端封面为空或图片加载失败
- **THEN** 卡片展示非破图的占位或无图布局，标题与详情链接仍可用

#### Scenario: 名片加载中不回退为标识

- **WHEN** 帖子列表已返回但对应名片请求尚未完成
- **THEN** 卡片作者区展示加载占位，不出现 26 位对外标识，也不阻塞标题与详情链接

#### Scenario: 名片缺失时降级

- **WHEN** 某条帖子的作者账户已注销或名片批量读取未返回该标识
- **THEN** 卡片展示统一的无头像与无昵称占位，不显示对外标识，不出现破图或空白文本
