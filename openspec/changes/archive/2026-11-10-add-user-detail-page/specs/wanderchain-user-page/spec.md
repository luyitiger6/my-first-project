# Spec Delta

## Purpose

让社区里的「人」有一个可落脚的主页：公开读取单个用户的四项资料与该用户的已发布帖子，内容流的作者区可直接进入该页，从而把社区关系从围绕内容推进到围绕人。

## ADDED Requirements

### Requirement: 公开用户资料的字段口径

已发布且未注销的用户资料 MUST 可被任何人按对外标识读取，返回昵称、头像、简介与兴趣标签四项；响应 MUST NOT 包含内部主键、邮箱、账户状态、软删除标记等内部字段。

#### Scenario: 游客读取用户资料

- **WHEN** 游客请求一个已发布且未注销用户的资料
- **THEN** 返回 200 与昵称、头像、简介、兴趣标签四项，且无需携带令牌

#### Scenario: 响应不含内部字段

- **WHEN** 读取任意可见用户的资料
- **THEN** 响应字段集合恰为对外标识、昵称、头像、简介与兴趣标签，不含内部主键、邮箱、账户状态与软删除标记

#### Scenario: 资料未填写时返回空值

- **WHEN** 用户未填写头像、简介或兴趣标签
- **THEN** 对应字段以空字符串或空数组返回，MUST NOT 省略字段

### Requirement: 公开用户资料的未找到口径

不存在、已注销或形状不合的对外标识 MUST 一律返回 404 与统一错误体，MUST NOT 用不同状态码或不同错误码区分原因，避免把这个公开端点变成标识的枚举信道。

#### Scenario: 不存在的标识

- **WHEN** 请求一个从未存在的对外标识
- **THEN** 返回 404 与固定错误码，响应结构与其他错误一致

#### Scenario: 已注销的用户

- **WHEN** 请求一个已注销用户的对外标识
- **THEN** 返回 404，且响应与该标识从未存在时完全一致

#### Scenario: 形状不合的标识

- **WHEN** 请求一个明显不合法的标识串
- **THEN** 返回 404 而不是 500，且响应不暴露解析细节

### Requirement: 用户页帖子列表的范围

用户页的帖子列表 MUST 只包含该用户已发布且未删除的帖子，按发布时间倒序、内部主键倒序兜底；草稿、已删除帖子与其他作者的帖子 MUST NOT 出现。

#### Scenario: 只返回该用户的已发布帖子

- **WHEN** 请求一个有多篇已发布帖子的用户
- **THEN** 每个列表项的作者对外标识都等于该用户，且不含该用户的草稿

#### Scenario: 已删除帖子不出现

- **WHEN** 该用户有一篇已删除的帖子
- **THEN** 列表中不包含该帖子

#### Scenario: 用户没有任何已发布帖子

- **WHEN** 请求的用户存在但一篇已发布帖子都没有
- **THEN** 返回 200 与空列表，MUST NOT 返回 404

#### Scenario: 未知用户得 404

- **WHEN** 请求一个不存在或已注销用户的帖子列表
- **THEN** 返回 404，响应与资料读取的未找到口径一致

### Requirement: 用户页帖子列表的分页

用户页帖子列表 MUST 使用游标分页，每页默认 20、上限 50；游标 MUST 只在该列表内有效，无法解码或不属于该列表的游标 MUST 被拒为 400。

#### Scenario: 游标继续下一页

- **WHEN** 用上一页返回的游标请求下一页
- **THEN** 返回紧跟其后的帖子，不重复、不跳过

#### Scenario: 非法游标

- **WHEN** 传入无法解码的游标
- **THEN** 返回 400 与统一错误体

#### Scenario: 条数钳制

- **WHEN** 请求的条数超过 50 或小于 1
- **THEN** 分别按 50 与默认值 20 处理

### Requirement: 用户页的入口与四态

已登录与未登录用户 MUST 都能从帖子卡片的作者区进入对应作者的用户页；用户页 MUST 覆盖加载、正常、空列表、读取失败、用户不存在五种可见状态，读取失败 MUST 提供重试，用户不存在 MUST 与空列表区分展示。

#### Scenario: 从帖子卡片进入用户页

- **WHEN** 用户在广场点击某张帖子卡片的作者名
- **THEN** 进入该作者的用户页并展示四项资料与该用户的帖子列表

#### Scenario: 游客可访问

- **WHEN** 未登录用户直接访问用户页路径
- **THEN** 资料与帖子列表正常展示，MUST NOT 跳转登录页

#### Scenario: 名片未就绪时不生成入口

- **WHEN** 帖子卡片的作者名片尚未返回
- **THEN** 作者区只展示占位，MUST NOT 以对外标识代替作者名，也不生成指向用户页的链接

#### Scenario: 用户不存在

- **WHEN** 用户页路径指向不存在或已注销的用户
- **THEN** 展示「用户不存在」态，MUST NOT 同时展示空列表态

#### Scenario: 读取失败可重试

- **WHEN** 资料读取失败
- **THEN** 展示可读错误与重试入口，重试后重新发起请求

#### Scenario: 用户没有已发布帖子

- **WHEN** 用户存在但列表为空
- **THEN** 资料正常展示，列表区展示空态文案
