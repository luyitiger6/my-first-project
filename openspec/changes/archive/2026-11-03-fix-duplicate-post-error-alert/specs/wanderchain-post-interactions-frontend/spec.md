# Spec Delta

## MODIFIED Requirements

### Requirement: 写操作去重与服务端校准

同一互动操作未结束时 MUST 防止重复请求；投票与收藏在自身写入和校准期间 MUST 禁止再次切换。成功写入后的校准失败 MUST 明确区分“已提交，刷新失败”与写失败，保持受影响状态未知并允许只重试读取，MUST NOT 自动重放写入或将旧统计标为最新。同一次失败 SHALL 只由一个业务提示承载：校准失败提示已呈现时，MUST NOT 再输出该次读取失败的第二个告警，且任何提示 MUST NOT 出现与该提示“不要重复提交”相矛盾的“请重试”指引。

#### Scenario: 连续点击只发一次

- **WHEN** 用户在同一次投票、收藏、评论提交或评论删除尚未结束时连续触发相同操作
- **THEN** 只发出一次写请求，并提供可感知的处理中状态

#### Scenario: 写成功但校准失败

- **WHEN** 写接口已成功，随后详情统计或个人状态读取失败
- **THEN** 页面只呈现一条业务提示，说明写入已提交、刷新失败且受影响数据待刷新，重试只发读取请求；同一次失败 MUST NOT 同时出现第二个告警，提示中 MUST NOT 出现与“不要重复提交”冲突的“请重试”指引
