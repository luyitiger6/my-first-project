模块采用经典的三层结构：`Application.java` 通过 `@SpringBootApplication` 启动；`web/TodoController.java` 暴露 `/api/todos` REST 接口（GET、POST、POST/{id}/complete），仅做请求转发；`domain/` 层包含不可变的 `Todo` record 与持有 `LinkedHashMap` 内存存储的 `TodoService`，刻意不引入数据库依赖以保证 Harness 验证回路的稳定性。测试位于 `src/test/java`，覆盖 `ApplicationContextTest` 与 `TodoServiceTest`。构建由 `pom.xml` 管理，继承 `spring-boot-starter-parent` 3.5.5，仅依赖 `spring-boot-starter-web` 与 `spring-boot-starter-test`；Flyway Maven Plugin 以迁移工具形式存在但不参与运行时。
