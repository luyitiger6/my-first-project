# U7 · 热门帖子区块

| 项 | 值 |
|---|---|
| 单元编号 | U7 |
| 归属能力 | `wanderchain-homepage` |
| 对应主 spec | `### Requirement: 热门帖子区块` — [spec.md](../../../openspec/specs/wanderchain-homepage/spec.md) |
| 规格层级 | 人读契约（`docs/specs/`，草稿层）。行为真相以主 spec 为准，冲突时按主 spec 验收 |

## 1. 边界

**包含**

- 最多展示 10 条**已发布**帖子
- 三级排序：评论数降序 → 浏览数降序 → 发布时间降序
- 每条展示：序号、标题、作者、评论数、浏览数、发布时间
- 空态：无匹配数据时展示空态文案
- 加载态与错误态（沿用区块三态）

**不包含**

- 发帖、编辑、删除
- 评论、点赞、收藏、关注
- 帖子详情页与无限滚动
- 草稿与已删除帖子的展示入口

## 2. 数据依赖

| 依赖项 | 形态 | 说明 |
|---|---|---|
| 帖子数据 | Mock 契约（U0 `mockRepository`） | 响应形状 `ListResult<Post>`；Mock 中确实存在草稿与已删除样本 |
| 状态过滤 | 静态（`ContentStatus`） | 只保留 `published`，`draft` 与 `removed` 一律排除 |
| 当前城市 | 静态（URL `?city=`） | 由 U5 写入、U2 透传 |
| 后端 API | **需要 API（本期未接）** | 未来对应「热门帖子榜」接口，另立项；本期零网络请求 |

## 3. 与其他单元的依赖

- **依赖**：
  - U0 —— 类型、Mock 数据、排序与截断逻辑
  - U5 —— 间接：按 `city` 过滤
- **被依赖**：U2 —— 区块由首页骨架挂载

## 4. 验收清单

- [ ] Mock 中已发布帖子多于 10 条时，区块只展示排序后的前 10 条
- [ ] 两条帖子评论数不同时评论数多者在前；相同时浏览数多者在前；都相同时发布时间晚者在前
- [ ] Mock 中存在草稿或已删除帖子时，这些帖子不出现在区块内
- [ ] 每条展示序号、标题、作者、评论数、浏览数、发布时间
- [ ] 无匹配数据时展示空态文案且不报错
- [ ] 全流程不发起网络请求

## 5. 实现位置

- 数据：`frontend/lib/home/repository.ts`
- 测试：`hot-posts.test.tsx`
